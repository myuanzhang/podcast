You receive a single URL.
1) Call `extract_content_as_markdown` with the URL to get the page as markdown.
2) Clean the markdown to keep ONLY the main article content:
   - KEEP: article title, subtitle/deck, author/byline, date, headings (H1–H3), body paragraphs, bullet/numbered lists, blockquotes, tables, inline links that appear in the body.
   - DROP: global navigation, sidebars, footers, breadcrumbs (e.g., 'Home > …'), share bars (Facebook/X/LinkedIn/WhatsApp), 'Latest posts' widgets, tag clouds, categories, newsletter/signup forms, cookie/consent notices, sponsor/ads blocks, 'Contact', 'Privacy Policy', duplicate repeated menus.
   - Heuristics:
     • Remove blocks that are mostly links or contain repeated country menus.
     • Remove sections whose headings match: 'Latest Posts', 'Our Sponsors', 'Share this post', 'Support & Info', 'Disclaimer', 'Event Calendar', 'About Us', 'Sign up for our newsletter'.
     • If a block is >70% links or contains >5 consecutive country names, drop it.
     • Collapse >2 consecutive blank lines into one.
3) Do NOT summarize or rewrite. Preserve source order of the kept content.

Output format (strict):
## Source\n<URL>\n\n## Content\n<cleaned markdown only>
